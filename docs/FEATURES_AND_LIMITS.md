## Критерии приёмки ТЗ (раздел 7)

| № | Критерий | Состояние | Как проверить |
|---|---|---|---|
| 1 | AI отвечает в Telegram | ✅ бот + агент; 🟡 ответы ChatGPT | написать боту после `chatgpt_login` |
| 2 | Сохраняет контекст | ✅ история и память в PostgreSQL, сводки | уточняющий вопрос без повторного объяснения |
| 3 | Использует знания компании | 🟢 RAG по 583 документам Салаватстекло | вопрос о продукте → ссылки [n] на сайт/посты |
| 4 | Создаёт контент | ✅ текст (агент) + изображение (шаблон Pillow) | «подготовь пост про …» |
| 5 | Поддерживает согласование | ✅ согласовать / на доработку с комментарием / отклонить | кнопки под постом в боте |
| 6 | Не публикует без разрешения | ✅ проверка хеша согласованного содержимого перед отправкой | отклонить пост → публикации нет |
| 7 | Публикует согласованный контент | ✅ Telegram (моки), 🟢 бот доступен; 🟡 реальный пост в канал | `/setchannel`, «Согласовать и опубликовать» |
| 8 | Выполняет задачу автономно | ✅ регулярные задачи (отчёт, обновление, сбор результатов) | `scripts.scheduler`, `manage run-task <slug> report` |
| 9 | Разделяет компании | ✅ фильтр company_id в SQL, роли, 404 для чужих | тесты `test_*isolation*` |
| 10 | Сохраняет состояние | ✅ всё в PostgreSQL | тест «история после перезапуска» |
| 11 | Настраивается без кода | ✅ бот `/newcompany`, `/addsource`, `/setchannel`, `/invite`; API | [NEW_COMPANY.md](NEW_COMPANY.md) |
| 12 | Способ использования ChatGPT | ✅ Sign in with ChatGPT; 🟡 демонстрация входа | `chatgpt_login`, `/ai` в боте, `GET /api/ai/connection` |

## Нефункциональные требования (раздел 5)

| Требование | Реализация |
|---|---|
| Сохранение после перезапуска | PostgreSQL; миграции Alembic |
| Защита от дублей публикаций | атомарный захват `scheduled → publishing`, message_id, без автоповтора зависших |
| Ошибки и уведомление администратора | ✅ публикации и задачи |
| Защищённое хранение учётных данных | токены ChatGPT и соцсетей — Fernet, файл 0600 / таблица `company_secrets`, наружу не отдаются |
| Изоляция клиентов | company_id из авторизации, инструменты без параметра company_id |
| Минимальные права | VK: `offline` для чтения, `wall,photos` только для публикации; бот — только «Публикация сообщений» |
| Запрет несанкционированных публикаций и расходов | согласование + дневной лимит AI на компанию, учёт расхода |
| Отзыв доступов, журнал | удаление участников и секретов, `ai/disconnect`, `audit_log` |
| Расширяемость | площадки (`platforms.py`), навыки (`@tool`), замена модели (`AIConnector`) без потери данных |

## Ограничения ChatGPT Plus (Sign in with ChatGPT, Preview)

* Документировано для open-source/локальных приложений и собственных VM; платный/облачный сервис для чужих
  компаний — только после одобрения заявки OpenAI ([CHATGPT_PLUS_OAUTH.md](CHATGPT_PLUS_OAUTH.md)).
* Общее 5-часовое окно лимита Plus для всех приложений пользователя; при исчерпании — пауза запросов и сообщение.
* Нет генерации изображений, file search, code interpreter, аудио/видео — поэтому изображения из шаблонов,
  эмбеддинги локальные.
* Без подключения AI-функции возвращают `AI_CONNECTION_UNAVAILABLE`; парсеры, поиск, согласование, публикация,
  отчёты по данным работают.
