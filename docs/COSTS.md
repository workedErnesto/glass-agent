## Сколько компаний выдержит одна подписка

Ограничение — не деньги, а общее 5-часовое окно лимита ChatGPT Plus (точный объём OpenAI не публикует).
Типовой расход вызовов модели (видно в `GET /api/admin/usage`):

| Действие | Вызовов модели |
|---|---|
| Вопрос в чате | 1–3 |
| Пост с картинкой и отправкой на согласование | 3–4 |
| Доработка по комментарию | 2 |
| Еженедельный отчёт с выводами | 1 |
| Черновик ответа на комментарий | 1 |

При ~10 постах и ~30 вопросах в неделю компания тратит порядка 100 вызовов в неделю. Ориентир для MVP —
3–5 активных компаний на одну подписку Plus; дневной лимит на компанию (`ai_daily_call_limit`, по умолчанию 300)
не даёт одной компании выбрать общее окно. Больше компаний — второй аккаунт/администратор или план Pro
(по документации OpenAI у Pro нет 5-часового окна) — после одобрения OpenAI для коммерческого размещения.

Время оператора: подключение компании ~30 минут ([NEW_COMPANY.md](NEW_COMPANY.md)), далее — только согласования.
