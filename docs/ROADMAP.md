# Доработки для коммерческого использования (п. 8.6 ТЗ)

## Обязательные до запуска
1. **Разрешение OpenAI на размещение** «Sign in with ChatGPT» в облачном сервисе для клиентов — заявка:
   https://openai.com/form/sign-in-with-chatgpt-interest/ . До одобрения — только установка у администратора/на его VM.
2. **Проверка на реальных аккаунтах**: ChatGPT Plus (ответы, лимиты, обновление токена), публикация в Telegram,
   VK (wall.post, фото, комментарии), MAX (публикация, загрузка изображений).
3. Подстройка промптов агента под реальную модель; оценка качества на наборе типовых поручений.
4. Mini App (Vue 3) — [FRONTEND.md](FRONTEND.md).
5. Резервное копирование БД и `data/` (включая `data/secrets/master.key`) по расписанию; мониторинг процессов.

## Продукт
* Влияние маркетинга на заявки и продажи: импорт заявок (CSV, CRM: amoCRM/Bitrix24), UTM-ссылки в постах.
* MAX: комментарии и диалог с ботом; VK: бот сообщества как второй интерфейс клиента.
* Генерация видео (сейчас — сценарии), локальная модель изображений на GPU.
* Отчёты в PDF, сравнение периодов, A/B заголовков.
* OCR для сканов PDF, загрузка документов прямо в бот.
* Правила согласования по компании: несколько согласующих, кворум, автосогласование для рубрик.

## Техника
* Нативные function tools ChatGPT вместо JSON-протокола; потоковые ответы чата (SSE) во фронтенд.
* Webhook вместо long polling для Telegram и MAX; очередь задач (несколько воркеров планировщика уже безопасны).
* SSRF: закрепление IP на время соединения (защита от DNS rebinding).
* Rate limiting API, метрики (Prometheus), трассировка, алерты администратору.
* Шифрование ключом из KMS/Vault вместо файла master.key; ротация ключей.
* Отдельный бот Telegram на компанию (секрет `telegram_bot_token` уже поддерживается при публикации).
* Нагрузочное тестирование RAG (HNSW-параметры, reranker `RERANKER_MODEL`).
